# 神農本草経（孫星衍輯本）原文・注・現代語訳

『神農本草經』（孫星衍・孫馮翼 輯，1799）の原文を，薬ごと・段落ごとの小さな単位に分け，資料間の異同（校異）・校訂，他の輯本・本草書・注釈書の対応する条（原文），現代語訳（日本語・英語）と組み合わせたもの。人が読むためだけでなく，LLM が読みやすいことを目指して，1単位を1ファイルにし，ファイルの頭に機械で読める情報（YAML）を付けている。

**現在の状況**：原文（全818単位）・校異・校訂・他の資料の条・注釈書（原文）と，訳の範囲の日本語訳・英訳ができている（2026-10-11）。姉妹編に[傷寒論](https://github.com/medicalcloud/shokanron)・[金匱要略](https://github.com/medicalcloud/kinkiyoryaku)・[黄帝内経](https://github.com/medicalcloud/koteidaikei)・[和剤局方](https://github.com/medicalcloud/wazaikyokuho)がある。

## 構成

```
NN_篇/
  index.md      単位の一覧
  NNN.md        薬の単位：原文＋校異・校訂・注釈＋他の資料の条（原文）＋注釈書（原文）
  pNNN.md       段落の単位（卷頭の序錄・薬名の一覧・小計・卷末の文，序，附録など）
  NNN.ja.md     日本語訳（訳ができたもの）
  NNN.en.md     英訳（同）
```

- 篇は 00 序（邵晉涵・張炯・孫星衍・周學海の序），01 上經，02 中經，03 下經，04 附録（附《吳氏本草》十二條・附諸藥制使），05 付録資料。
- 01〜03 の薬の単位（`001`…）は孫本の並び順の通し番号。薬でない段落（卷頭の序錄・薬名の一覧，部ごとの小計，下經の末の序錄の文）は `p001`… とした。00・04・05 は段落ごと。
- 薬の単位の原文は，名，名の下の注（「（舊作…）」など），本文（経文），《吳普本草》の引用，《名醫》（別錄）の引用，孫の考証「案」の順。孫本で一つと数える薬（生大豆・赤小豆を附く大豆黄巻）は一つの単位とした。六芝は孫本の見出しどおり6単位に分けた。
- 05 付録資料：薬の条に入らない他の資料の原文。徐大椿『百種錄』・陳修園『讀』の序と凡例，『讀』だけにある薬の条，行政院中醫藥委員會本（四卷本）と通行本の序錄，孫本にない薬の条。

## 底本と，本文の補い・訂正

### 底本

- **どのような本か**：清の孫星衍・孫馮翼が輯めた『神農本草經』（1799）の，問經堂叢書本（孫の初刊）。
- **どのように入手したか**：中醫笈成（jicheng.tw）が問經堂叢書本から校正して公開している電子テキストを，中醫笈成のデータ（gitlab.com/jicheng/jc.data。公有の典籍への編集は CC0）の HTML から，2026-10-11 に取得して使った。句読点は中醫笈成のもの。
- **字の変換**：日本の新字体に直した（方針は `字体と変換の方針.md`）。簡体字から戻したときに生じたらしい一対多の字の誤り（「陶弘景雲」→云，「生川穀」→川谷，「範子計然」→范，「肉鬆蓉」→松，「症瘕」→癥 など）は，全用例を文脈つきで確かめて直した（校異には記さない）。
- **薬の分け方**：中醫笈成本で見出しのない薬（五色石脂・黑芝・蠡魚・雷丸）は，段落の形から分けた。

### 底本に足りないところ

- 底本の「囗」は底本の欠字で，補っていない。「⿱艹…」などの組み合わせの表記は，字のないものとしてそのまま残した。

### 訂正（校訂）

- 本文などを改めたのは86か所（見出しの名5を含む）。孫本の別の版（Wikisource 本・殆知閣本・行政院本）と，同じ薬の条を載せる資料（行政院の四巻本，通行本，『証類本草』，『新修本草』，『名医別録』の輯本など）を比べて，一番それらしい字を採った。資料が一致しなくても改めたところがある。
- 改めたところには【校訂】として，元の字句・各資料の字・改めた理由を記した。
- 孫星衍が意図して古い字を使ったもの（瘨・痙・要・卮 など）は改めていない。

### 照合した資料

- **孫本の別の版**：Wikisource「神農本草經 (孫星衍)」，殆知閣「神农本草经」（孫星衍），行政院中醫藥委員會の文本 CM098（中醫笈成「神農本草經_2」。本文だけ）。Wikisource 本と殆知閣本は同じ電子テキストの系統で，共通の変換の誤り（「毒瓦斯」「浓朴」「野狼毒」など）や欠字がある。
- **校異**：孫本の別の版と底本の字句の違い（258件）。「X は「…」に作る」「…の間に，X は「…」がある」の形。字体・異体字・繁簡の違い，古今字（臓/蔵・腑/府・仙/僊），簡体字では区別できない字（殆知閣本の並/并・著/着・於/于・覆/復 など），句読点，他の資料の欠落，資料自体の変換の誤り・文字化けは記していない。
- **他の資料の条（原文）**：各薬に，次の資料の対応する条を引いた（名の別名・異体で対応させた）。
  - 輯本：行政院中醫藥委員會の文本 CM096（中醫笈成「神農本草經_1」。序錄を卷一とする四卷本），編者不明の通行本（Wikisource「神農本草經」）
  - 本草書：『證類本草』（中醫笈成。重修政和證類本草。条の最初の段落＝本經と別錄の文だけ），『新修本草』（中醫笈成。天平三年古寫本の影鈔本。条の最初の段落だけ。残っていない巻の薬はない），『名醫別錄』『吳普本草』（中醫笈成の輯本）
- **注釈書（原文）**：徐大椿『神農本草經百種錄』，陳修園『神農本草經讀』（中醫笈成）。訳はしない。
- **扱っていないもの**：『本草經集註』（見出しの構造が揃わないため），『太平御覽』『千金翼方』の引用。森立之・顧觀光の輯本（電子テキストが見つからない）。

## 訳の範囲

日本語訳・英訳と解説は，薬の本文・《吳普本草》・《名醫》，卷頭の序錄・薬名の一覧・小計，卷末の序錄の文，附録に付ける。孫の考証（案）と4つの序，他の資料の条・注釈書・付録資料は原文だけ（後で訳を足せる形にしてある）。

## English summary

This repository presents the *Shennong bencao jing* (Divine Farmer's Classic of Materia Medica) as compiled by Sun Xingyan and Sun Fengyi (1799), split into one file per drug or paragraph with YAML metadata. Each drug file contains the punctuated original text (the classic text with the quotations from *Wu Pu bencao* and *Mingyi bielu* and Sun's notes), textual variants and emendations, the corresponding entries from other compilations and materia medica (*Zhenglei bencao*, *Xinxiu bencao*, etc.), and the commentaries of Xu Dachun and Chen Xiuyuan (original text only). Japanese and English translations are provided for the classic text, the Wu Pu and Mingyi quotations, the prefatory and closing sections, and the appendices. The base text is the edition on Zhongyi Jicheng (jicheng.tw, CC0). Classical texts are in the public domain; new material is CC BY-SA 4.0. Translations were produced with an LLM and may contain errors; not for clinical use.
